## Architecture
- `domain/` — types only (no DB, no HTTP)
- `repo/` — DB access (`*pgxpool.Pool`); `pgx.ErrNoRows` → `repo.ErrNotFound` at repo layer
- `biz/` — service logic; never leak raw pgx errors
- `handlers/` — HTTP; use `respond.JSON(w, status, v)` and `respond.Error(w, status, "CODE", "msg")`
- Router: chi v5
- Tests: testify; in-memory fakes in `_test.go`; NO testcontainers for unit tests
